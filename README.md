## ✨ Возможности

- 🎫 Выдаёт случайный номер билета от **1 до 20**.
- 👤 Запрашивает фамилию и имя; пробелы по краям удаляются.
- ✅ Не принимает пустые поля и повторяет запрос.
- 📗 Записывает студента, билет и дату/время в `journal.xlsx`.
- ➕ Добавляет записи в конец файла, сохраняя предыдущие строки.
- 💾 Сохраняет каждую запись сразу после ввода студента.
- 🔒 При блокировке файла сообщает об ошибке и предлагает повторить сохранение.
- ⎋ Завершает работу при нажатии **ESC** во время ввода.

## 🧰 Требования

- Windows 10 или новее
- Python 3.10+
- Excel-файл создаётся автоматически; Microsoft Excel для работы приложения не нужен

## 🚀 Запуск

Откройте терминал в папке проекта и выполните:

```powershell
python -m pip install -r requirements.txt
python main.py
```

При запуске появится подсказка:

```text
Генератор экзаменационных билетов
Для выхода нажмите ESC.

Last name:
```

Введите фамилию и имя, подтверждая каждое поле клавишей **Enter**. После этого приложение покажет, например, `Билет № 7` и сразу сохранит запись. Чтобы закончить работу, нажмите **ESC** во время ввода любого поля.

## 📊 Формат журнала

Файл `journal.xlsx` хранится рядом с `main.py`. При первом запуске он создаётся автоматически с заголовками:

| A | B | C | D |
|---|---|---|---|
| Last name | First name | Номер билета | Дата и время |

Каждый студент записывается отдельной строкой. Повторный запуск продолжает журнал, не заменяя уже сохранённые записи.

## 🔐 Если Excel-файл открыт

Если `journal.xlsx` открыт в Excel и сохранение заблокировано, приложение покажет сообщение. Закройте файл в Excel и нажмите **Enter** в консоли — сохранение будет повторено. **ESC** отменит только текущую несохранённую запись.

## 🧪 Проверка

Для запуска автоматических проверок выполните:

```powershell
python -m unittest -v
```

Тесты проверяют создание журнала с заголовками и добавление новой строки без изменения предыдущих записей.
